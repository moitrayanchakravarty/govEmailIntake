# src/components/registry/

Components specific to the "registry" feature/domain — e.g. a table listing
registry entries (`RegistryTable.jsx`).

This folder is an example of a **feature-scoped component group**: it only
contains pieces relevant to one feature, imported by the pages in
`pages/user/` and/or `pages/portalManager/` that display registry
data. Treat each feature folder under `components/` the same way as you add
new domains to the app.
